# Banking-System
This is a simple console-based banking application implemented in Python. It allows a user to perform basic banking operations such as checking balance, depositing money, and withdrawing money. The program runs in a loop until the user chooses to exit.


# Features:

1.Show Balance: Displays the current account balance in a formatted manner.

2.Deposit: Allows the user to deposit an amount into their account. The program validates that the amount entered is positive and numeric.

3.Withdraw: Allows the user to withdraw an amount from their account. The program checks that the amount is numeric, positive, and does not exceed the available balance.

4.Exit: Terminates the program with a thank-you message.

# Input Validation:

Prevents entering negative amounts for deposit or withdrawal.

Prevents withdrawing more money than the available balance.

Handles invalid (non-numeric) inputs gracefully.

# User Interface:

Menu-driven console interface.

Provides clear prompts and messages to guide the user through banking operations.

# Usage:

1.Run the program in Python (e.g., in VS Code).

2.Enter the number corresponding to the action you want to perform.

3.Deposit or withdraw amounts as needed.

4.Select Exit to close the program.
